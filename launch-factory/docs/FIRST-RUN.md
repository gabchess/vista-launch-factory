# First run

## Goal

Complete one gated Run that ends in a **Claims Lock draft for Barry**, not a published launch.

## Preconditions

- Skill installed for your host ([INSTALL-CODEX.md](INSTALL-CODEX.md) or [INSTALL-CLAUDE.md](INSTALL-CLAUDE.md)).
- One release folder with Loom / outline / footage (or labelled fixture when available).
- You accept that slots **1 / 5 / 6** are HOLD stubs in v0.1.0.

## First ask

> Run Launch Factory on this release folder.

## Expected flow

1. Ingest / retrieve from the folder.
2. Draft Claims Lock (traceable claims only — no invent).
3. **Stop for Barry** on Claims Lock before fan-out.
4. After Barry lock: adapters for blog / email / changelog when engine is live; HOLD stubs for video / login / popup.
5. Validate ≤2 loops.
6. Barry pack approve → package + honesty note (name the HOLDs).

## Do not

- Ask the pack to publish, send, or “just push to HubSpot.”
- Treat Writer output as Barry approval.
- Claim all six outputs are review-ready while 1/5/6 are held.
