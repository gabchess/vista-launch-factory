# Tix writing gate

This review covers the writing baseline for the first Tix article. The two approved videos remain accepted.

**Reader:** someone shopping for secondhand gear. **Example:** a used Sony camera in Brooklyn, with a personal limit below $950.

**Direction:** introduce Tix through the buyer’s decision, explain the current price-check foundation, then describe supported discovery and optional capped checkout as the product direction.

**Voice:** approachable Tix product-team prose, with short attributed character lines where useful. **CTA:** Join the waitlist · tixmancer.xyz.

## Proposed statements

### TIX-C01

Tixmancer is a conversational product for people looking for secondhand finds.

Use constraint: Describe the product, without claiming public production access.

### TIX-C02

The intended starting point is a conversation about the item, location and personal price limit.

Use constraint: Use design/preview framing; do not claim a live external search.

### TIX-C03

Tix compares an asking price with the buyer’s chosen limit. That comparison alone does not establish market value.

Use constraint: Refer to the selected preview behavior. Preserve the distinction between under budget and below market value.

### TIX-C04

The selected preview code is designed around account-owned conversations and saved context.

Use constraint: Code/design only; deployed Google sign-in and AI Gateway acceptance were not tested here.

### TIX-C05

The selected preview uses stored simulations for marketplace, notification and wallet steps.

Use constraint: Keep this boundary in explanations of what can be tried; a product-vision scene proves no real external event.

### TIX-C06

Tix’s roadmap includes supported marketplace sources, selected notifications and an optional wallet for a supported seller.

Use constraint: Explicit future tense. No existing coverage, notification delivery or wallet execution claim.

### TIX-C07

The planned purchase flow uses an optional wallet and spending permission with a cap, expiry, approval and revocation.

Use constraint: Explicitly planned; keep supported seller and verification prerequisites. Do not say that connecting a wallet enables purchases today.

### TIX-C08

The product’s canonical address is tixmancer.xyz.

Use constraint: The domain is supported. An active public waitlist collection flow was not verified.

## Keep out of the article

Unverified marketplace coverage, under-market savings, completed consumer purchases, public provider acceptance, historical payment success, pricing, commercial programs, traction and funding. The source documents retain historical payment prose; this campaign does not use it as an allowed claim.

The exact waitlist CTA remains selected. Its collection flow needs verification before publication.
