Show the post behind each review task

A clear review starts when the task points to the exact social post.

Your approval queue has a task that says “Approve the next post.”

Which one? The version from this morning, or the one still in drafts? Has feedback already landed somewhere else? Did someone already sign off, or is that still pending?

None of that lives in the task. Before anyone can approve, someone has to find the actual post, check who’s weighed in, then figure out the stage. When the task only says “Approve the next post,” finding the real post and context can take longer than the decision itself.

In Vista Work, the task and social posts are linked. Open the task and you see the actual post content, not a card describing it. Approvers can see what needs a decision instead of hunting for the post first.
