## User paths to prove

1. As an operator, I want to submit a repository link or release folder and see what was read, so that I can correct missing source material.
2. As an operator, I want to answer only missing audience, voice and campaign questions, so that a familiar release needs little setup.
3. As a reviewer, I want readable copy and playable media beside the relevant sources and comments, so that I can decide without searching another tool.
4. As a reviewer, I want to request a focused revision and compare versions, so that accepted work survives an edit.
5. As a reviewer, I want approval to identify the exact content version, so that a later change cannot inherit my earlier decision.
6. As an operator, I want progress and pending decisions to survive reloads, so that I can return while a media job finishes.
7. As an operator, I want a clear failure reason and safe retry choice, so that recovery does not duplicate charges or erase accepted work.
8. As an operator, I want the whole campaign and weekly calendar in one downloadable package, so that I can hand it to the people who will publish it.
9. As an installation maintainer, I want documented setup, account checks and recovery steps, so that the client can operate its own copy.
10. As an invited tester, I want to complete the normal flow through the app, so that an engineer's hidden intervention is unnecessary.
