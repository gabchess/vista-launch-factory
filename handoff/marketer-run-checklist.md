**Controlled companion to:** VISTA-LF-HANDOFF-001 / v0.1.1 (Working Draft)  
**Use by:** Marketer (Run operator)  
**Stop and escalate when:** kill-switch armed; urge to publish/send; CIO as Vista ESP; second pack into `awaiting_barry`; inventing claims; treating an undemonstrated trigger button as live automation

## Ready

- [ ] Fixture labelled **or** Reggie real folder confirmed (never unclear)
- [ ] No other campaign in `awaiting_barry` (WIP=1)
- [ ] Folder has Loom/transcript + GitHub outline + footage index (or fixture equivalents)
- [ ] Claim ledger linked; forbidden list present before Barry Claims Lock
- [ ] Barry surface known; writer seat ≠ Barry
- [ ] `trigger_used` plan known: demonstrated automation trigger/Drive **or** `manual_rehearsal` (automation Run = demo leave-behind until proved)
- [ ] Crew available for local validate/package **or** prior pass already on the Campaign row (marketer does not open a terminal)

## Execute

- [ ] Start Run via demonstrated trigger **or** manual rehearsal, record `trigger_used` on the row
- [ ] Confirm ingest/retrieve visible
- [ ] Barry **Claims Lock** approve (not Slack thumbs) before adapters
- [ ] First real (non-HELD) slot drafted → Barry spot-check (skip O1 when O1 is HELD; for this campaign first-real-slot = O2 blog)
- [ ] Remaining O2 to O6 + cadence binder (same `campaign_id`); held slots have reasons; HELD slots are not the spot-check gate
- [ ] Crew validate ≤2; marketer confirms pass/fail on row; no hard-fail advance
- [ ] Submit pack `awaiting_barry` (WIP=1)
- [ ] Barry pack approve **or** Request Changes on **named** slots only → re-run those slots
- [ ] Crew package + honesty doc; marketer confirms; MANIFEST `auto_publish: false`
- [ ] Optional: HubSpot **sandbox drafts only** after approve, or skip

## Close

- [ ] Status `packaged`, `review_ready_pre_claims_lock` (pre-Claims-Lock review bundle only), or `sandbox_exported` (or documented `held`)
- [ ] No production publish; CIO not presented as Vista ESP
- [ ] Honesty table included
- [ ] If Request Changes path used: only named slots regenerated; versions bumped
- [ ] Did **not** claim unattended automation live; G12 durable trigger still open until demonstrated

**Interrupted work resumes from:** Campaign `status` checkpoint, never skip Claims Lock or Barry after drafting resumes.

**Builder ≠ maintainer:** builders/crew change tools and run local scripts; marketing uses the demonstrated automation trigger (after trigger proved) or manual rehearsal for day-to-day Run, never a marketer terminal requirement in this draft.
