# Handoff SOP (superseded)

This document was an early working-draft standard operating procedure, written before
the current `engine/` implementation existed. It describes a tracker, a Notion or Gumloop
run trigger, and a Customer.io integration that were never built and do not appear
anywhere else in this repository. It also links to design documents (`DESIGN-LOCK.md`,
the 2026-09-07 design and plan files) that are not part of this repository.

Treat it as historical planning material only. It does not describe how the system
actually works today.

For the current, accurate operating model, read:

- [README.md](../README.md) for what the system does and how to run it.
- [docs/OPERATE-LAUNCH-FACTORY.md](../docs/OPERATE-LAUNCH-FACTORY.md) for the runtime spine.
- [docs/HUMAN-GAPS.md](../docs/HUMAN-GAPS.md) for what still needs a human, and why.
- [handoff/ENGINEER-START-HERE.md](ENGINEER-START-HERE.md) for engineer setup.

Recommended for deletion on the next cleanup pass.
